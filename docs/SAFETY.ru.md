# Правила безопасности

Toolkit’и рассчитаны на **боевые BIM-серверы**. В публичном коде те же границы.

## Жёсткие правила

1. Для workshared / `RSN://` — **Create New Local**. Не Detach живые centrals для Apply.
2. **Audit ≠ Apply.** Отчётные скрипты не делают Save / Sync / Relinquish.
3. **Узкий Apply.** Явный список моделей (например, только БФ), не «все 80 разделов».
4. **Без автокоординации.** Internal Origin, PBP / Survey, True North, Shared Coordinates / Site — руками или только в отчёте.
5. **Допуски обязательны.** Без мм/градусов шум округления даёт ложные RED.
6. В MVP Apply **не удалять** уровни/оси. Missing / extras → в отчёт.
7. **XLSX без Excel COM** на UNC (OpenXML + локальная папка вывода).
8. **RSN-патч** (контур units) — инфраструктура: стоковый RBP режет `RSN://` на `File.Exists`. Патчить Scripts только осознанно.

## Зачем это на собеседовании

Показывает автоматизацию процессов с **контролем риска**, а не «скрипт, который меняет всё подряд».
