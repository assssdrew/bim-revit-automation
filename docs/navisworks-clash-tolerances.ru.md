# Допуски на коллизии Navisworks (черновик матрицы)

Справочный черновик для Clash Detective: что проверять, какие допуски ставить на **стадии П** и **стадии Р**, что **исключать** из теста.

> Источник обсуждения: внутренняя таблица «Допуски на коллизии» (ещё не разнесена по П/Р).  
> Числа ниже — **стартовая точка для согласования**, не корпоративный стандарт. Подставьте свои значения из DOCX после сверки.

Связанные правила портфолио: [SAFETY.ru.md](SAFETY.ru.md) — без допусков отчёт превращается в шум.

---

## Как читать матрицу

| Колонка | Смысл |
|---------|--------|
| **Пара** | Selection Set A ↔ Selection Set B (не «вся модель ↔ вся модель») |
| **Тип** | Hard / Hard (Conservative) / Clearance / Duplicates |
| **П** | Стадия П: ловим системные пересечения, терпимее к шуму моделирования |
| **Р** | Стадия Р: жёстче hard + осмысленные clearance под монтаж/обслуживание |
| **Исключить** | Правило Ignore / фильтр категории — иначе ложные New |

Правило оператора: сначала **Hard** по критичным парам → группировка → согласование → потом **Clearance**. Не смешивать всё в один тест.

## Hard-коллизии (пересечение геометрии)

Допуск Hard = «игнорировать пересечение меньше N мм» (шум округления / касание).

| Пара (A ↔ B) | Тип | Допуск П | Допуск Р | Комментарий |
|--------------|-----|----------|----------|-------------|
| КР несущие ↔ ОВ воздуховоды | Hard | 25 мм | 10 мм | Приоритет КР; на Р — ближе к монтажной точности |
| КР несущие ↔ ВК трубопроводы | Hard | 25 мм | 10 мм | То же |
| КР несущие ↔ ЭОМ лотки / шинопроводы | Hard | 25 мм | 10 мм | |
| КР несущие ↔ АУПТ (трубы/спринклеры) | Hard | 25 мм | 10 мм | |
| ОВ ↔ ВК | Hard | 20 мм | 10 мм | Междисциплинарный конфликт |
| ОВ ↔ ЭОМ | Hard | 20 мм | 10 мм | |
| ВК ↔ ЭОМ | Hard | 20 мм | 10 мм | |
| АР стены/плиты ↔ ОВ/ВК/ЭОМ (магистрали) | Hard | 25 мм | 10 мм | Не путать с намеренными проходками |
| АР ↔ КР (несущие vs стены) | Hard | 15 мм | 5–10 мм | Часто шум LOD; смотреть осмысленные пересечения |
| Оборудование ОВ/ВК/ЭОМ ↔ КР/АР | Hard | 15 мм | 5–10 мм | |
| Самопроверка раздела (Duplicates) | Duplicates | 10 мм | 5 мм | Копии элементов в одной модели |
| Самопроверка раздела (Hard self) | Hard | — | по BEP | Только если явно нужно QA; иначе много шума |

На П допустимо шире (25 мм), чтобы не тонуть в «волосках». На Р сужаем до 5–10 мм.

## Clearance (мягкие / технологические зазоры)

В Navisworks тип **Clearance**: срабатывает, если расстояние **меньше** заданного зазора.

| Пара (A ↔ B) | Зазор П | Зазор Р | Зачем |
|--------------|---------|---------|-------|
| Воздуховод (с изоляцией) ↔ КР | 0 / off* | 50 мм | Монтаж / изоляция |
| Трубопровод (с изоляцией) ↔ КР | 0 / off* | 50 мм | |
| Лоток ↔ воздуховод | 0 / off* | 50–100 мм | Доступ, крепёж |
| Спринклер ↔ низ балки / перекрытия | по нормам / off | 100–150 мм | Уточнять по СП/NFPA проекта |
| Оборудование ↔ зона обслуживания | схематично | 600–1000 мм† | Access; лучше отдельный набор «зоны обслуживания» |
| Кабельный лоток ↔ трубопровод с горячим носителем | off | 100+ мм | Тепло / доступ |

\* На стадии П clearance часто **выключают** или ведут выборочно по шахтам/техэтажам — иначе отчёт нечитаем.  
† Значение зоны обслуживания — из задания/паспорта оборудования, не «с потолка».

## Что точно исключать (Ignore / не класть в Selection Sets)

Список «точно требуется исключать» — то, о чём просили в обсуждении. Без этого Clash Detective заливает New ложными.

### Геометрия / категории

1. **Арматура ЖБ ↔ бетон** (если оба в модели) — ожидаемое пересечение.  
2. **Огнезащита / обмазка ↔ КР**.  
3. **Изоляция труб/воздуховодов ↔ «родитель»** (если изоляция отдельным элементом и уже учтена в clearance).  
4. **Болты, сварные швы, пластины узлов ↔ профили** того же узла КР.  
5. **Импосты / панели витража** внутри одной системы АР.  
6. **Отделки пола/потолка ↔ несущая плита** (при раздельном моделировании пирога).  
7. **Мебель / оборудование интерьера ↔ АР** в hard-тестах координации инженерки (отдельный сценарий, если нужен).  
8. **Помещения (Rooms/Spaces), зоны, линии осей, уровни, 2D-аннотации** — не геометрические clash-объекты.  
9. **Временные / демонтируемые** элементы, фазы «существующее к сносу» — по правилам фаз проекта.  
10. **Дубли связей** (одна и та же модель подгружена дважды) — чинить сборку NWF, а не разбирать clash.

### Намеренные пересечения

11. **Гильзы, отверстия, штрабы, проёмные семейства** ↔ проходящие сети — вести отдельным статусом / правилом, не как New hard.  
12. **Крепёж сетей к КР** (хомуты, подвесы), если смоделирован и «врезается» в балку.  
13. **Закладные / пластины** под оборудование.  
14. **Шумоглушители / врезки** на стыках систем внутри одного раздела — обычно self-noise.

### Правила отчёта

15. Ранее **Approved / Reviewed** коллизии с тем же GUID/парой — не поднимать заново без смены геометрии.  
16. Коллизии **внутри одного Selection Set**, если тест задуман как междисциплинарный.  
17. Элементы ниже порога значимости (например, трубы &lt; Øxx на П) — если так зафиксировано в BEP.

## Предложения, что добавить в таблицу (если ещё нет)

Имеет смысл явно прописать строки:

| Тема | Почему |
|------|--------|
| Разделение **П / Р** отдельными колонками или листами | В чате: таблица ещё не отсортирована на П и Р |
| Статус коллизии: New / Active / Reviewed / Approved / Resolved | Иначе «допуск» путают со статусом согласования |
| Правило **группировки** (по уровню, системе, grid) | 1 воздуховод × 10 балок = 1 issue |
| Отдельные тесты **шахты / техэтаж / кровля / паркинг** | Разная критичность и зазоры |
| Clearance **только на Р** + список пар | Не смешивать с hard на П |
| Исключение **арматура / огнезащита / изоляция / гильзы** | Самый частый источник ложных |
| Пары **АУПТ ↔ всё** и **слаботочка ↔ силовые** | Часто забывают в первой версии матрицы |
| Допуск на **Hard (Conservative)** — когда включать | Параллельные трубы «почти касаются» торцами |
| Кто **владелец** пары (дисциплина-ответчик) | Для назначения в Clash Detective |
| Ссылка на **Selection Sets / Search Sets** (имена) | Чтобы матрица = воспроизводимый тест |
| Версия матрицы + дата + проект | Иначе разъедутся NWF у разных координаторов |

## Минимальный набор тестов (чтобы не утонуть)

1. КР ↔ ОВ (Hard)  
2. КР ↔ ВК (Hard)  
3. КР ↔ ЭОМ (Hard)  
4. ОВ ↔ ВК (Hard)  
5. ОВ ↔ ЭОМ (Hard)  
6. АР (стены/плиты) ↔ магистрали ОВ/ВК/ЭОМ (Hard)  
7. Duplicates по каждому разделу (точечно)  
8. На Р: 2–3 Clearance-теста по BEP (изоляция / лотки / спринклеры)

## Санитизация

В публичном репозитории **нет** корпоративных UNC, IP и персональных путей. Живой DOCX остаётся во внутреннем файловом обмене; сюда — только обезличенная матрица и правила.

Когда пришлёте актуальный DOCX/скрины — можно заменить числа в таблицах на ваши и разметить «уже есть / предложено добавить».
