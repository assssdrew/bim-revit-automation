Сжатие моделей Revit
====================


Что в этой папке
----------------
Сжатие.vbs       — запуск окна
ИНСТРУКЦИЯ.txt   — этот текст
отчеты           — сюда пишутся Excel после прогона
служебное        — первый запуск RBP и запасные ярлыки

Остальные файлы трогать не нужно.


Что нужно на этом компьютере
----------------------------
1. Revit тех лет, которые есть в списке (2021–2025).
   Хост Revit Server 2025 прописан в servers.cfg как
   SET-REVIT-SERVER-2025-HOST — замените его на настоящий адрес,
   иначе сервер 2025 в списке не откроется.
2. Revit Batch Processor (RBP).
   https://github.com/bvn-architecture/RevitBatchProcessor/releases

Скрипт сам по себе модели не открывает. Окно запускает RBP, RBP открывает Revit.


Два сценария
------------
Ручной эталон (как координатор делает в Revit):

  1. Открыть хранилище с проверкой.
     Локальный файл не создавать. Отсоединять не надо.
  2. Сохранить как хранилище: «Сжать файл», открытие наборов — «Задать».
  3. Синхронизироваться со сжатием и закрыть.

В окне это два режима.


Сценарий 1. Быстрый
-------------------
Когда: по необходимости, команда может оставаться в файлах.
Лёгкий режим. Его не убираем, но он сжимает слабее глубокого:
нет проверки при открытии и нет пересохранения хранилища,
только синхронизация с галочкой «Сжать файл».

Что делает:
  — открывает через «создать новый локальный»;
  — проверку при открытии не ставит;
  — рабочие наборы при открытии: закрыть все;
  — сжимает хранилище синхронизацией с галочкой «Сжать файл»;
  — закрывает сессию.
  Чужие локали не ломает.

В окне: переключатель «Быстрое». Подтверждение не спрашивает.


Сценарий 2. Глубокий  (как руками)
----------------------------------
Когда: раз в месяц / квартал.

Цель: сильно уменьшить файл, не ломая локали проектировщиков
и не удаляя семейства (это не «Очистить неиспользуемые»).

Перед запуском:
  1. Сделать бэкап хранилища.
  Проектировщиков выгонять не нужно: наборы не занимаются,
  чужие локали остаются рабочими.

Что делает (тот же порядок, что ручной эталон):
  1. Открывает хранилище с проверкой.
     Локальный файл не создаёт. От хранилища не отсоединяет.
     Наборы (в том числе связей) при открытии закрыты.
  2. Сохраняет как то же хранилище: сжать файл, наборы — «Задать».
  3. Синхронизируется со сжатием и закрывает.

После прогона:
  — чужие локали актуальны, создавать заново не нужно;
  — проектировщики синхронизируются как обычно.

В окне: глубокое включено сразу.


Как запустить
-------------
1. Дважды щёлкните  Сжатие.vbs
2. Добавьте модели:
     Файлы…         — отдельные .rvt
     Папки…         — папка проекта, берёт рабочие модели (резерв пропускает)
     Revit Server…  — модели с сервера
3. Список можно экспортировать в текстовый файл и в следующий раз импортировать.
   Для ежемесячного прогона удобно держать один такой список.
4. Отметьте модели галочками (сразу после добавления они сняты).
   «Выделить все» / «Снять выделение» — сразу весь список. Сжимаются только отмеченные.
   «Очистить выбранные» убирает подсвеченную строку (одну или несколько).
   Если строка не подсвечена, убираются строки с галочкой.
   «Очистить список» очищает всё. Клавиша Delete убирает подсвеченные строки.
   Клик по заголовку столбца сортирует список (повтор — в обратную сторону).
5. Выберите режим (глубокое или быстрое).
   Галочка «Параллельно» — отдельный Revit на каждый год
   (2021, 2022, 2023, 2024, 2025 и local, если год не определился).
   Внутри одного года модели по-прежнему идут по очереди.
   Без галочки годы идут один за другим, как раньше.
6. Нажмите «Сжать». Окно не закрывается: у текущей модели видно «Идёт 3:42».
   Чёрное окно RBP скрыто. Если что-то упало — сообщение на экране и путь к логу.
   Пока идёт прогон, Windows просят не уходить в сон. После окончания запрос снимается.
   Окно на это время не закрывайте.
7. Кнопка «Открыть отчёт» становится активной после этого прогона.

Годы Revit в списке могут идти вразнобой.
Без «Параллельно» окно само разберёт их и прогонит по очереди.
Руками делить список по годам не нужно.

Revit Server в окне выбора — это веб-служба (HTTP), не папка Windows.
Уровни: проект, затем стадия, затем папка, затем модель.
Двойной щелчок или «Открыть» заходит внутрь. «Добавить папку» забирает
модели из выделенной ветки, включая вложенные.

Без окна (планировщик): служебное\run_list.cmd и служебное\CLI.txt.


Отчёты
------
Если в папку скрипта можно писать:

  …\ORG_CompactModels\отчеты\

Если папка только на чтение — на этом компьютере:

  %LOCALAPPDATA%\BatchRvt\batch_compact_save\отчеты

Имя файла: дата_время_год_проект_report_режим.xlsx
Пример: 2026-09-24_1530_R24_proj_SampleSite_report_deep.xlsx
Список, который сохраняют кнопкой «Экспорт списка», называется так же,
только с models.txt в конце.
Несколько лет в одном прогоне — Rmix, несколько проектов — mixed,
год не определился — Rlocal. Режим в имени: deep или quick.

Листы:
  Модели    — по проекту, затем по имени. Колонки вес до / после / дельта.
              «новая» = да, если модели не было в прошлом отчёте того же режима.
  Сводка    — итог прогона, в том числе сколько новых.
  Проекты   — сколько моделей, сколько новых, вес до / после / дельта по проекту.

Листа «Динамика» больше нет: сравнение с прошлым разом — колонка «новая».
В параллельном режиме у каждого года свой файл отчёта.

В окне можно включить «Открыть отчёт после прогона» или нажать «Открыть отчёт».


Первый запуск Revit
-------------------
Если Revit спрашивает разрешение надстройки BatchRvt:

  1. Закройте Revit полностью.
  2. Запустите  служебное\разрешить_надстройку_BatchRvt.cmd
  3. Сразу откройте Revit Batch Processor.

Окно «Всегда загружать» иногда всё равно нужно нажать руками.


Лицензия Revit при старте
-------------------------
Иногда при первом запуске года Revit спрашивает вход Autodesk или ключ.
Скрипт это окно не закрывает и ключ никуда не записывает: подстановка
клавиш ломается от версии к версии, а серийный номер нельзя хранить в папке.

Что сделать на компьютере, где гоняют сжатие:

  1. Один раз открыть каждый нужный год (2021–2025) вручную под той же
     учётной записью Windows, под которой потом идёт RBP или планировщик,
     и дождаться, пока лицензия примется.
  2. Проверить, что служба Autodesk Desktop Licensing Service запущена.
  3. Для сетевой лицензии — чтобы в LMTOOLS было свободное место.
     Для однопользовательской — чтобы лицензия была выдана этому пользователю.
  4. Не запускать прогон из другой учётки: у неё лицензии может не быть,
     и Revit будет ждать окно, пока RBP не оборвёт задачу по таймауту.

Если окно лицензии всё равно всплывает в батче, это настройка лицензии
на компьютере, а не ошибка списка моделей.


Нельзя
------
Не сжимайте копии из  RVT\Резерв\ГГГГ-ММ-ДД\
У них путь к живому хранилищу может быть неверным.

Это не zip и не «Очистить неиспользуемые».
Сжимается сам файл хранилища (галочка «Сжать файл»).


Общая папка
-----------
Toolkit можно положить на файловый сервер. Список моделей (`rvt_list.txt`)
и отчёты пишутся локально, если шара только на чтение.

Запускать с того компьютера, где стоят Revit и RBP.
