Запуск без окна (планировщик, цепочка)
======================================

Скрипт: start_compact.ps1 (в корне папки инструмента)
Ярлык:  служебное\run_list.cmd
Этот файл и naming.ps1 лежат в служебное\, не в корне.

Окно «Сжатие» при этом не открывается. Revit и Revit Batch Processor
на этом компьютере всё равно нужны: скрипт только запускает RBP.

Параметры
---------
-ListPath <файл>
    Текстовый список моделей, один путь на строку.
    Строки с # пропускаются. Подходят .rvt и RSN://.
    Если параметр не задан, берётся текущий rvt_list.txt
    (шара или %LOCALAPPDATA%\BatchRvt\batch_compact_save).

-Mode quick | deep
    quick — быстрое (лёгкое) сжатие: локаль и синхронизация со сжатием.
            Файл уменьшается слабее, чем в deep.
    deep  — глубокое: хранилище с проверкой и пересохранение со сжатием.
    По умолчанию для этого входа: deep.

-Parallel
    Отдельный процесс Revit / RBP на каждый год (2021, 2022, 2023,
    2024, 2025 и local для путей без года). Внутри одного года модели
    идут по очереди. Без этого ключа годы идут один за другим.
    В параллельном режиме у каждого года свой отчёт.

-NonInteractive
    Не задавать вопросов в консоли. Для планировщика задач обязателен.
    Тот же эффект, если указаны -Mode, -ListPath или -Parallel.

Код выхода: 0 — RBP завершился без ненулевых кодов, 1 — ошибка запуска
или ненулевой код RBP, 2 — неверные параметры.

Примеры
-------
Только список, глубокое, годы по очереди:

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File start_compact.ps1 -NonInteractive -Mode deep -ListPath C:\lists\models.txt

Быстрое и параллельно по годам:

  powershell.exe -NoProfile -ExecutionPolicy Bypass -File start_compact.ps1 -NonInteractive -Mode quick -Parallel -ListPath C:\lists\models.txt

Через ярлык (параметры дописываются в конец):

  служебное\run_list.cmd -Mode deep -ListPath C:\lists\models.txt

Планировщик
-----------
Программа:  powershell.exe
Аргументы:  -NoProfile -ExecutionPolicy Bypass -File "C:\...\start_compact.ps1" -NonInteractive -Mode deep -ListPath "C:\lists\models.txt"
Учётная запись: та же, под которой Revit уже лицензирован (см. инструкцию, раздел про лицензию).
Окно «Сжатие» должно быть закрыто: оба входа пишут в один каталог отчётов.

Пока идёт прогон, скрипт просит Windows не уходить в сон
(SetThreadExecutionState) и снимает запрос после выхода RBP.
Компьютер не должен выключаться, и сеанс этой учётки не должен завершаться.

Имена списка и отчёта
---------------------
yyyy-MM-dd_HHmm_R24_Проект_models.txt
yyyy-MM-dd_HHmm_R24_Проект_report_deep.xlsx

Rmix — в списке несколько лет. Rlocal — год не определился.
mixed — в списке несколько проектов. na — проект не определился.
quick | deep — режим в имени отчёта латиницей.
