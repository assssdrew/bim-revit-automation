# Служебные файлы Revit Batch Processor

Обычный Revit Batch Processor отклоняет пути `RSN://`. Для глубокого режима без нового локального файла он отсоединяет общую модель.

При нажатии **Сжать** окно само готовит установленный RBP. Отдельно этот каталог запускать не нужно.

Версия маркера: `RSN_PATCH_PS_v4`.
