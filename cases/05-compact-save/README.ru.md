# Кейс 05 — Сжатие workshared-моделей (Compact)

[← К хабу](../../README.ru.md) · [EN](README.md)

## Проблема

Хранилища Revit раздуваются после месяцев синхронизаций. Нужная галочка Autodesk — **«Сжать файл»** в Сохранить / Синхронизироваться с хранилищем, это не zip и не «Очистить неиспользуемые». Вручную: год Revit, открыть хранилище (или новый локальный), сжать, Sync, Relinquish, закрыть — и так по папке или Revit Server.

## Решение

Операторское окно (`Сжатие.cmd` → WinForms). Человек выбирает модели (файлы / папки / `RSN://`), режим, жмёт «Сжать». Toolkit сам раскладывает список по годам Revit и гоняет API-задачу; [Revit Batch Processor](https://github.com/bvn-architecture/RevitBatchProcessor) — только хост батча.

| Режим | Когда | Что делает |
|-------|--------|------------|
| **Быстрый** | По необходимости; команда может оставаться в файлах | Create New Local, закрыть наборы, `SynchronizeWithCentral` с **Compact = True**, Relinquish. Чужие локали не ломает. |
| **Глубокий** | Раз в месяц / квартал | Сначала все выходят. Открывает **хранилище с Audit** (без нового локального, без Detach) → Сохранить как хранилище со сжатием → Sync Compact. После прогона коллеги создают локаль заново. |

Excel: вес до / после, сводка прогона, динамика к прошлым отчётам.

## Масштаб / контекст проекта

| | |
|--|--|
| Статус | Использовалось в работе на одном проекте; автотестов нет |

## Безопасность

- Compact — это **запись**. Глубокий режим = окно обслуживания: бэкап, предупредить команду, никто не синхронизируется во время прогона.
- Быстрый: Create New Local, Detach **OFF**.
- Глубокий: открытие хранилища + Audit; живое хранилище не Detach. В окне — подтверждение, что все вышли.
- Не сжимать резервные / датированные копии (например, `RVT\Backup\…`) — путь к живому хранилищу может быть неверным.
- Это не Purge Unused и не zip `.rvt`.

Подробнее: [docs/SAFETY.ru.md](../../docs/SAFETY.ru.md)

## Запуск

1. Скопировать `src/` на ПК с Revit и RBP
2. Прописать хосты в `servers.cfg` (в этом репо — заглушки)
3. Дважды щёлкнуть `Сжатие.cmd`
4. Добавить модели → Быстрый или Глубокий → Сжать
5. Первый запуск Revit: если BatchRvt блокируется — `служебное\разрешить_надстройку_BatchRvt.cmd`
