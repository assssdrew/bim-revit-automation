Операции с моделями Revit
=========================
Переименование, перенос, смена версии Revit, перепривязка связей,
уборка старых файлов. Всё из одного окна.


Что в этой папке
----------------
Операции с моделями.vbs  — запуск окна
ИНСТРУКЦИЯ.txt           — этот текст
README.md                — подробное описание для разработчика
servers.cfg              — адреса Revit Server по годам
служебное                — весь код, запасные .cmd-ярлыки, патч RBP, тесты

Рабочие файлы (rvt_list.txt, job_paths.csv, mapping.csv и др.)
появляются здесь, в корне, после работы окна. Их можно открывать,
но удалять во время прогона нельзя.

В папку «служебное» заходить не нужно.


Что нужно на этом компьютере
----------------------------
1. Revit нужных лет (2021–2025).
2. Revit Batch Processor (RBP).
   https://github.com/bvn-architecture/RevitBatchProcessor/releases


Как запустить
-------------
1. Дважды щёлкните  Операции с моделями.vbs
2. Выберите вкладку. У каждой вкладки свой список моделей:
   «Файлы…», «Папки…», «Revit Server…» или «Взять с вкладки…».
   Отметьте модели галочками.
3. Заполните поля вкладки (ниже). Ошибка в поле — красная
   строка внизу окна, запуск не пойдёт.
4. «Пробный прогон» показывает план и ничего не меняет.
5. Кнопка справа внизу запускает вкладку. Окно само
   запускает нужные проходы RBP.

Перенос и переименование
  Имя: было → стало. «Было» подставлено (первая модель),
  «стало» — каким должно стать. Пустое «стало» — имя не меняется.
  Папка: было → стало. Пустое «стало» — модели остаются в своей
  папке. Проверьте колонки «Станет» и «Новый путь»; строка
  с ошибкой пути не даст запустить прогон.
  Старые модели: «оставить» (по умолчанию) или перенести
  в _to_delete после проверки. Перезапись — только галочкой.

Перепривязка связей
  «Старая папка» и «Новая папка» связей. «Из переноса» берёт
  папки с первой вкладки. Модели не переименовываются.

Смена версии Revit
  Текущая версия определяется сама (Revit Server — по servers.cfg,
  сетевой файл — по _R22/_R24 в имени). Выберите только целевую
  версию: в списке лишь версии новее. Модели разных лет —
  отдельными запусками.


Связи: добавить  и  Рабочие наборы
----------------------------------
1. Отметьте модели. Новые модели раздела пометьте «новая»
   (правая кнопка на списке вкладки «Связи: добавить»).
2. «Прочитать наборы и связи» (или «Открыть отчёт чтения…»
   для готового отчёта). Проверьте таблицу: целевая модель,
   связь, набор. Пустое имя набора и строка без пары запуск
   не дадут.
3. «Вставить связи» / «Записать наборы» показывают, что будет
   сделано. По умолчанию выбрано «Нет».
4. «Да» вставляет связи только по общим координатам. Если
   координаты не согласованы, эта связь пропускается.
   Удаление набора по умолчанию переносит его элементы
   в набор по умолчанию; «вместе с элементами» — только
   если вы это выбрали.

Нужны пути Revit Server (RSN) или сетевые папки.
BIM 360 и диск в этом режиме не используются.


Служебное (без окна)
--------------------
служебное\run_cascade.cmd             — старое меню по пунктам
служебное\presets.cmd                 — открыть окно через консоль
служебное\choose_models_path.cmd      — составить rvt_list.txt
служебное\move_centrals.cmd           — перенос по job_paths.csv
служебное\delete_old_models.cmd       — уборка старых в _to_delete
служебное\reset_report_session.cmd    — новая сессия отчётов
служебное\patch_rbp_open_failures.cmd — патч RBP (кириллица в окнах Revit)
служебное\snap_ui.ps1                — снимки окна и проверка раскладки

Перенос и уборка сначала всегда делают пробный прогон (dry-run)
и ничего не меняют. Применить — набрать YES.


Отчёты
------
Папка «отчёты» рядом с этим файлом (создаётся при работе).


Нельзя
------
Не запускайте на живых моделях без бэкапа.
Старые файлы не удаляются, а переносятся в _to_delete рядом с ними.
С Revit Server ничего не удаляется: только список to_delete_rsn.txt.
