# Кейс 02 — Health Check моделей

[← К хабу](../../README.ru.md) · [EN](README.md)

## Проблема

BIM-менеджеру нужен еженедельный сигнал «здорова ли модель» по многим centrals — CAD, in-place, лишние типы, дальняя геометрия, состав связей — без ручного открытия каждого файла и без риска Save/Sync.

## Решение

Read-only аудит RBP (**v1.4.0**):

- Метрики волнами A / B / C
- Светофор из `thresholds.cfg`
- CSV по моделям + **один цветной XLSX** в конце батча (OpenXML, без Excel COM)
- Листы: Сводка + Связи (RVT)

## Скриншот

Лист Excel с проверкой связей. Имена моделей и пути размыты.

![Excel, проверка связей Revit. Имена моделей и пути размыты.](../../docs/img/health_check_links.jpg)

## Масштаб / контекст проекта

| | |
|--|--|
| Статус | Применялось на одном проекте; только чтение (без изменений модели) |
| Эффект | Метрики здоровья и инвентаризация RVT-связей по многим centrals в одном цветном XLSX и пакетном CSV |
| Пишет в модель? | **Нет** |
| Масштаб | Тот же picker, что у units |

## Безопасность

- Никогда Save / Sync / Relinquish
- Локалы после прогона лучше закрыть без сохранения
- Координатные *метрики* могут быть в отчёте; *правки* координат — вне scope

## Запуск

1. Скопировать `src/` в Scripts RBP
2. `choose_models_path.cmd`
3. `reset_report_session.cmd` → папка XLSX
4. RBP: `health_check.py` + `rvt_list.txt`
5. Пересборка: `color_latest_report.cmd`
