# Кейс 03 — Уровни и оси (Audit / Apply)

[← К хабу](../../README.ru.md) · [EN](README.md) · [Пример CSV](../../samples/levels_grids_details_sample.csv)

## Проблема

После каждого обновления архитектуры базовые файлы (БФ), а затем модели разделов должны совпасть с эталоном по **уровням и осям** (имена, отметки, положение и угол осей, дубли, лишние и недостающие). Ручной просмотр Copy/Monitor не масштабируется.

## Решение

Каскад для RBP. **Audit v1.21.0** только пишет отчёт. **Apply v1.23.0** меняет только строки, которые оператор отметил в окне плана правок.

1. **Audit БФ ↔ АР** (эталон = связь АР) → CSV / Excel
2. **Правка БФ по отчёту** — выбор моделей и проблем, затем Apply
3. **Audit разделов ↔ БФ**
4. **Правка разделов по этому отчёту** — то же окно, только модели разделов

Меню: [`src/run_cascade.cmd`](src/run_cascade.cmd). Сравнение идёт через Revit API, не через окно просмотра координаций. Геометрия переводится в координаты хоста. Пороги — в `tolerances.cfg`.

Окно плана (`choose_fix_plan.ps1`) показывает каждую строку отчёта. Фильтры: Уровни / Оси / только RED. Одна галочка включает Sync после прогона. Сдвиг базовой точки проекта по X/Y/Z (миллиметры; Z с минусом — вниз) пишется только для отмеченных моделей, нулевой сдвиг в план не попадает.

## Масштаб / контекст проекта

| | |
|--|--|
| Статус | Проверено на рабочих моделях |
| Эффект | В среднем примерно в 4–5 раз быстрее, чем вручную; каскад БФ↔АР и разделы↔БФ сессиями отчётов |
| Недельная нагрузка | ~5–6 БФ, затем до ~80 разделов |
| Пороги по умолчанию | Уровень 2 мм · Ось 5 мм · Угол 0,1° |
| Версии | Audit `SCRIPT_VERSION` **1.21.0** · Apply `SCRIPT_VERSION` **1.23.0** |

## Безопасность

| В scope | Вне scope |
|---------|-----------|
| Имена, отметки, положение осей, дубли, лишние/недостающие, светофор | Internal Origin, Survey Point, True North, Shared Coordinates, площадка |
| Apply: только отмеченные строки плана. Сдвиг базовой точки — только по этим моделям | Создание и удаление уровней и осей. Слепая автоправка |

Audit не вызывает Save / Sync / Relinquish. Apply синхронизирует модель только если галочка в плане включена.

Пока БФ не совпал с АР, прогон разделов — лишняя работа.

Подробнее: [docs/SAFETY.ru.md](../../docs/SAFETY.ru.md)

## Запуск

1. Скопировать `src/` на ПК с нужным годом Revit и RBP
2. Прописать хосты в `servers.cfg` (в этом репо — заглушки)
3. `run_cascade.cmd` → **1** (audit БФ) или `choose_models_path.cmd`, затем RBP: `levels_grids_audit.py` (Create New Local, Detach выкл)
4. После отчёта: пункт **2** (БФ) или **4** (разделы) открывает план, пишет `fix_plan.csv` и `rvt_list.txt`, затем `levels_grids_apply.py`
5. Пересобрать Excel: `color_latest_report.cmd`

`fix_plan.csv` и `last_selection.cfg` — локальные файлы прогона, в репозиторий не кладутся.
