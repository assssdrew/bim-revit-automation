# Типовые этажи — инструкция

[English](INSTRUCTION.md)

Скрипт выгружает помещения квартир (совмещённый санузел, уборная, гардеробная) из связанной модели АР в Excel. Excel сам находит одинаковые этажи и заполняет «Таблицу 1». В Revit ничего не считается и модель не меняется.

## 1. Что лежит в папке

Пример папки отчётов (подставьте свой путь; в репозитории корпоративного пути нет):

`\\server\share\Project\Scripts\TypicalFloors`

| Файл | Что это |
|------|---------|
| `Типовые_этажи.dyn` | Граф Dynamo. Его запускают. |
| `Типовые_этажи_ШАБЛОН.xlsx` | Шаблон отчёта. Не открывать для правки, не переименовывать, не удалять. |
| `Export_AR_to_Excel.py` | Копия кода узла (для справки, для запуска не нужен). |
| `build.py` | Заново собирает шаблон. Для запуска не нужен. |
| `Типовые_этажи_K01.xlsx`, `…_K04.xlsx`, … | Отчёты по корпусам. Появляются сами после первой выгрузки корпуса. |
| `Типовые_этажи_ОШИБКА.xlsx` | Появляется, только если скрипт не нашёл связь АР. Внутри — причина. |

Все файлы должны лежать в одной папке. Скрипт ищет шаблон в папке, указанной во входе «Папка отчётов».

## 2. Первая настройка (один раз на компьютере)

1. Revit → вкладка «Управление» → «Проигрыватель Dynamo».
2. В окне проигрывателя нажмите значок папки («Изменить папку») и выберите папку, где лежит `Типовые_этажи.dyn`. Проигрыватель её запомнит.
3. У графа «Типовые_этажи» в поле «Папка отчётов» укажите ту же папку (в ней лежит `Типовые_этажи_ШАБЛОН.xlsx`). Поле «Связь АР» оставьте пустым.

Если сетевой папки не видно в окне выбора:

- Откройте папку в Проводнике → правый клик по папке → «Закрепить на панели быстрого доступа».
- Снова откройте выбор папки — она появится слева в «Быстром доступе».

Окно выбора папки не даёт вписать UNC-путь с клавиатуры. Если закрепить папку не получается, откройте `.dyn` в Dynamo, замените узел «Папка отчётов» (Directory) на узел **String**, впишите путь одной строкой без пробелов по краям и без переноса:

`\\server\share\Project\Scripts\TypicalFloors`

Отметьте узел «Является входным», соедините его со вторым входом узла «Выгрузка АР», сохраните (Ctrl+S).

Чтобы Dynamo не предупреждал о файле из сети: Dynamo → «Настройки» → «Безопасность» → «Доверенные расположения» → добавьте эту папку.

## 3. Выгрузка корпуса (каждый раз)

1. Закройте в Excel все файлы `Типовые_этажи_*.xlsx`.
2. Откройте модель ОВ нужного корпуса. Связь АР этого корпуса должна быть загружена.
3. «Управление» → «Проигрыватель Dynamo» → у строки «Типовые_этажи» нажмите запуск.
4. Дождитесь «Выполнено».
5. Откройте `Типовые_этажи_Kxx.xlsx`, где `Kxx` — код корпуса из имени связи АР.

Пример имени связи (вымышленное): `PRJ_AR_01_K04_R24.rvt` → файл `Типовые_этажи_K04.xlsx`. Если файла корпуса ещё нет, он создаётся из шаблона. Готовить файлы заранее не нужно.

Поле «Связь АР» заполняют только когда в модели загружено несколько связей АР (см. раздел 7). Если связь АР одна, скрипт выбирает её сам.

Запускайте граф из Проигрывателя. Если открыть тот же граф в редакторе Dynamo и нажать «Запуск», не изменив код узла Python, редактор может не выполнить узел повторно и выгрузка не обновится.

## 4. Что смотреть в отчёте

| Лист | Что на нём |
|------|------------|
| Типовые этажи | Этажи сгруппированы: одинаковые — один цвет и один номер группы (например, 7–12). Справа вверху — дата и время выгрузки. |
| Таблица 1 | Этаж \| Номер \| Тип \| Комнат \| Sобщ \| Sж \| СУ \| Уборная \| Гардеробная. |
| Выгрузка | Сырые строки из Revit. Руками не править: при следующей выгрузке лист заменяется. |
| Настройки | Корпус, учёт типа квартиры, имена помещений (раздел 6). |
| Инструкция | Краткая памятка внутри книги. |

Если цифры не обновились — F9 (пересчёт).

## 5. Повторная выгрузка того же корпуса

Файл корпуса целиком не перезаписывается: заменяется только лист «Выгрузка». «Типовые этажи» и «Таблица 1» пересчитываются по новым данным. Правки на листе «Настройки» сохраняются. Файлы других корпусов не затрагиваются: имя файла берётся из имени связи АР, поэтому отчёт одного корпуса не затирает другой.

Перед запуском файл корпуса должен быть закрыт в Excel.

`Data.ExportExcel` с перезаписью удаляет лист «Выгрузка» и создаёт его заново. Обычные ссылки на этот лист превращаются в `#REF!`. Формулы шаблона читают «Выгрузку» через `INDIRECT`, поэтому после замены листа они остаются целыми.

## 6. Новый объект или другие параметры АР

Имена помещений — на листе «Настройки» (формулы не трогать):

- В столбцах СУ / Уборная / Гардеробная перечислены варианты имён. Если в АР помещение называется иначе (например, «С/у»), впишите вариант в пустую ячейку нужного столбца.
- «Учитывать тип квартиры при поиске типовых этажей»: «нет» — сравниваются только наборы помещений; «да» — ещё и типы квартир.

Имена параметров в самом скрипте (если у АР другие параметры):

1. Откройте `Типовые_этажи.dyn` в Dynamo.
2. Двойной щелчок по узлу «Выгрузка АР».
3. Измените только блок НАСТРОЙКИ вверху. Строки `KLWT_*` — пример имён общих параметров одного заказчика, не обязательный стандарт:

```python
P_FLOOR = "KLWT_Этаж"                     # этаж
P_TYPE  = "KLWT_Тип квартиры"             # тип квартиры
P_NUM   = "KLWT_Номер квартиры на этаже"  # номер квартиры
P_SOBSH = "KLWT_Площадь квартиры общая"
P_SZH   = "KLWT_Площадь квартиры жилая"
ROOM_NAMES = ["Совмещенный санузел", "Санузел", "Ванная", "Уборная", "Туалет", "Гардеробная"]
```

4. «Принять изменения», затем Ctrl+S.

Новое имя помещения добавляют в двух местах: в `ROOM_NAMES` скрипта (иначе помещение не выгрузится) и на листе «Настройки» (иначе оно не попадёт в столбец СУ / Уборная / Гардеробная). Для новых корпусов правьте шаблон, для уже созданных — их файлы.

Другая папка отчётов: поменяйте вход «Папка отчётов» (или строку String, если узел заменён, как в разделе 2).

## 7. Ошибки и что делать

| Что видно | Что делать |
|-----------|------------|
| Появился `Типовые_этажи_ОШИБКА.xlsx` | Связь АР не найдена. На листе «Выгрузка» — причина и список связей. Загрузите связь («Управление связями» → «Обновить/Загрузить»). |
| «Загружено несколько связей АР» | Впишите в поле «Связь АР» часть имени нужной связи, например `K04`. Сравнение не зависит от регистра, разделителей (`_`, пробел, `-`, `.`) и парных букв кириллица/латиница (А/A, К/K, …). Так имя `…_01_…` не цепляет `…_02_…` из‑за похожей буквы, а одна загруженная связь АР выбирается без фильтра. |
| «Закройте файл … и запустите снова» | Файл корпуса открыт в Excel. Закройте и запустите ещё раз. |
| «Нет шаблона Типовые_этажи_ШАБЛОН.xlsx в папке …» | Шаблона нет в указанной папке: его удалили или переименовали, либо путь ведёт не туда. В папке должен лежать файл шаблона. |
| «Папка отчётов не найдена» | Нет доступа к папке или опечатка в пути. Проверьте, открывается ли папка в Проводнике. |
| В отчёте нули или пусто | Нажмите F9. Проверьте, что в АР заполнены параметры из блока НАСТРОЙКИ и имена помещений совпадают с листом «Настройки». |
| Предупреждение «Use ExportToExcel instead» | Не ошибка. На результат не влияет. |

## 8. Ограничения

- На компьютере должен быть установлен Microsoft Excel (`Data.ExportExcel`).
- Revit 2024, узел Python — CPython3.
- До 15 квартир на этаже, 80 этажей, 1500 квартир, 3000 строк выгрузки на корпус.
- Макросов нет. Файл `.xlsx` открывается в Excel 2010 и новее.
- Скрипт только читает помещения связи АР. Модель ОВ он не сохраняет и не синхронизирует.
