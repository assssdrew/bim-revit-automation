| **test_align_schedules** — `IndexError` в `run.rows` (~все тесты на `Run`) | Тест пишет заголовок отчёта в текстовом режиме с `"\r\n"`. На Windows Python переводит `\n`→`\r\n`, получается `\r\r\n`; при чтении появляется пустая строка, `rows[0] == ['']`, а `summary` берёт `r[1]`. **Почему 102 пропущено.** Все классы, где стоит `@unittest.skipUnless(PWSH, "нет pwsh")`, пропускаются, потому что тесты ищут PowerShell 7 (`pwsh`, `tests/test_chain.py:26`, `test_partial.py:21`), а на Windows есть только `powershell.exe` 5.1. На Linux без `pwsh` пропускается 101 тест (проверено прогоном без `PWSH`), на Windows — ещё один (браузерный тест Viewer, `test_viewer.py:33`, нет Playwright/Chromium). Затронуты все тесты логики на PowerShell: `project_config`, `partial`, `chain`, `ui_layout`, `revit_versions`, `report_layout`, `portability` и др. **Следствие:** на Windows проверена только Python-часть; PowerShell-код на Windows автотестами не гоняется. Как исправить: поставить PowerShell 7 (`winget install Microsoft.PowerShell`) или `set PWSH=powershell.exe` (часть тестов рассчитана на pwsh 7 и может потребовать правок). Крит.: **С**.
