# Проверочные спецификации (batch_verification_schedules)

Пакетно копирует проверочные спецификации Revit из файла-источника в модели разделов ИОС, выгружает результаты в Excel (сводка, разделы, динамика) и при желании отправляет их в Google-таблицу.

**Только Windows + Revit + Revit Batch Processor (RBP).** PowerShell 5.1, WinForms, IronPython в Revit. В облаке/Linux запустить нельзя — там можно только править код и гонять тесты из `tests/`.

## Запуск

`Проверочные спецификации.vbs` → окно `ui_schedules.ps1`. Подробно для пользователя — `ИНСТРУКЦИЯ.txt`.

## Раскладка папки

В корне только нужное пользователю: `Проверочные спецификации.vbs` (запуск), `ИНСТРУКЦИЯ.txt`, `servers.cfg`, `отчеты\` (создаётся сама), `служебное\`, `.gitignore`. Всё остальное — в `служебное\`: `скрипты\` (все рабочие `.ps1`/`.py`, в т. ч. `ui_schedules.ps1`), `lib\` (`DocumentFormat.OpenXml.dll`), `choose_models.ps1` (его вызывает окно), `google_push\`, `rbp_rsn_patch\`, `разработка\` (`инструменты\` — служебные .bat BIM-менеджера и разовые/диагностические скрипты фильтров; тесты и техническая документация: этот README, `АРХИТЕКТУРА_цепочки.md`, `ФАЙЛЫ_ОТЧЕТОВ.md`). Отдельной сборки нет: на общий компьютер копируется сама папка.

## Устройство

| Файл | Роль |
|---|---|
| `folder_dialog.ps1` | `Show-FolderPathDialog` — единственное окно выбора папки (адресная строка, UNC) |
| `служебное\скрипты\ui_schedules.ps1` | главное окно: выбор моделей, наборов, запуск RBP, отчёты |
| `insert_schedules.py` | задача RBP: вставка спецификаций в модель |
| `export_schedules.py` | задача RBP: выгрузка значений спецификаций |
| `project_config.ps1`, `project_dist_ui.ps1` | вкладка «Распределение»: настройка проекта `отчеты\проект\распределение_<префикс моделей>.txt` — единственный источник наборов спецификаций и профиля (стадия) |
| `read_template_specs.py` | задача RBP: чтение списка спецификаций из шаблона |
| `build_assignment.ps1`, `assignment_xlsx.ps1`, `assignment_export_stream.ps1` | сборка xlsx-задания через OpenXML (`lib/DocumentFormat.OpenXml.dll`, без Excel) |
| `excel_isolated.ps1` | Excel COM — запасное чтение xlsx для Google, если нет `google_push_payload.json` |
| `report_xlsx.ps1` | отчёт прогона (Сводка/Вставлено/Параметры/Пропуски) в xlsx без Excel: zip + XML |
| `push_google.ps1`, `google_payload_lib.ps1`, `google_push_cfg.ps1` | отправка в Google Apps Script |
| `служебное/google_push/Code.gs` | веб-приложение Apps Script (секрет — в «Свойствах скрипта») |
| `служебное/разработка/инструменты/dump_schedule_filters.*`, `compare_filter_*`, `Выгрузить/Сравнить фильтры спек.bat` | выгрузка фильтров всех спецификаций модели (только чтение) и сравнение двух выгрузок (см. `служебное/разработка/инструменты/СРАВНЕНИЕ_ФИЛЬТРОВ.md`) |
| `servers.cfg` | Revit Server: `host|имя|год` |

Цепочка и исправленные ошибки — `АРХИТЕКТУРА_цепочки.md`.

## Настройка Google

Скопируйте `служебное/google_push/google_push.cfg.example` → `google_push.cfg` и впишите URL веб-приложения и `PUSH_SECRET`. **`google_push.cfg` в git не коммитится** (`.gitignore`).

## Тесты

Тесты лежат в `служебное/разработка/tests` (см. `tests/README.md` там же): `python tests/test_chain.py`, `python tests/test_filter_replace.py`, `node tests/code_gs_mock_test.js`, `powershell -File tests/ps_unit.ps1`.

## Выходные файлы (`отчеты\`)

`отчеты\` — итоговые xlsx; `отчеты\история\` — постоянные файлы (не удаляются); `отчеты\служебные\<время>\` — файлы прогона (автоочистка старше 30 дней, `auxkeepdays=` в `ui_settings.txt`); `отчеты\операции\` — CSV и дампы служебных .bat. Старые файлы при первом запуске переносятся автоматически, ничего не удаляется. Подробно — `ФАЙЛЫ_ОТЧЕТОВ.md`. После «Собрать задание» путь к xlsx — в строке статуса, кнопка «Открыть папку» выделяет файл в проводнике.

## Не хранится в git

`__pycache__/`, `отчеты/`, `google_push.cfg`, сгенерированные списки.

Исходные таблицы проекта (чек-лист, матрица ИОС, правила разнесения): `project/PROJ/Проверочные спецификации/`.
