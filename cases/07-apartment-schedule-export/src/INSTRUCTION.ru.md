# Выгрузка квартирографии — инструкция

[English](INSTRUCTION.md)

Скрипт выгружает помещения квартир (совмещённый санузел, уборная, гардеробная) из связанной модели АР в Excel. Excel сам находит одинаковые этажи и заполняет «Таблицу 1». В Revit ничего не считается, модель ОВ не меняется.

## 1. Где что лежит

Папка скрипта — одна на все проекты. В этом репозитории путь-заглушка (подставьте свою папку):

`\\server\share\BIM\Dynamo\Выгрузка квартирографии`

| Файл | Что это |
|------|---------|
| `Выгрузка_квартирографии.dyn` | Граф Dynamo. Его запускают. |
| `Квартирография_ШАБЛОН.xlsx` | Шаблон отчёта. Не открывать для правки, не переименовывать, не удалять. |
| `Выгрузка_квартирографии.py` | Копия кода узла (для справки, для запуска не нужен). |
| `Инструкция_Выгрузка_квартирографии.docx` | Та же инструкция в Word. |
| `build.py` | Заново собирает шаблон. Для запуска не нужен. |
| `mk.py` | Заново собирает docx. Для запуска не нужен. |

Папка отчётов создаётся сама рядом с открытой моделью ОВ:

- Обычная модель: папка модели ОВ `\Квартирография`.
- Модель совместной работы: папка файла-хранилища `\Квартирография`.

| Файл в папке «Квартирография» | Что это |
|-------------------------------|---------|
| `Квартирография_K01.xlsx`, `…_K04.xlsx`, … | Отчёты по корпусам. Появляются после первой выгрузки корпуса. |
| `Квартирография_ОШИБКА.xlsx` | Появляется, только если скрипт не нашёл связь АР. Внутри — причина. |

В папке скрипта отчёты не появляются. Модель ОВ должна быть сохранена на диске или на сетевой шаре. Для модели в облаке (BIM 360 / ACC) и для Revit Server (`RSN://`) папку рядом создать нельзя.

Строка `SCRIPT_DIR` в узле Python должна указывать на папку скрипта, где лежит шаблон.

## 2. Первая настройка (один раз на компьютере)

1. Revit → вкладка «Управление» → «Проигрыватель Dynamo».
2. В окне проигрывателя нажмите значок папки («Изменить папку»).
3. Выберите папку скрипта (путь выше). Проигрыватель её запомнит, и «Выгрузка_квартирографии» останется в списке.

Если сетевой папки не видно в окне выбора:

- Откройте папку в Проводнике → правый клик по папке «Выгрузка квартирографии» → «Закрепить на панели быстрого доступа».
- Снова откройте выбор папки — она появится слева в «Быстром доступе».

Чтобы Dynamo не предупреждал о файле из сети: Dynamo → «Настройки» → «Безопасность» → «Доверенные расположения» → добавьте эту папку.

Входа «Папка отчётов» больше нет. Единственный вход проигрывателя — «Связь АР».

## 3. Выгрузка корпуса (каждый раз)

1. Закройте в Excel все файлы `Квартирография_*.xlsx`.
2. Откройте модель ОВ нужного корпуса. Связь АР загружена, модель сохранена.
3. «Управление» → «Проигрыватель Dynamo» → у строки «Выгрузка_квартирографии» нажмите запуск.
4. Дождитесь «Выполнено».
5. Откройте папку «Квартирография» рядом с моделью ОВ (для совместной работы — рядом с файлом-хранилищем) и файл `Квартирография_Kxx.xlsx`. Пример: `Квартирография_K04.xlsx`.

Номер корпуса скрипт берёт из имени связи АР. Пример имени (вымышленное): `PRJ_AR_01_K04_R24.rvt` → `K04`. Если папки или файла корпуса ещё нет, они создаются сами: файл — копией шаблона из папки скрипта.

Поле «Связь АР» оставьте пустым, если загружена одна связь АР. Заполняют его, только когда связей АР несколько (раздел 7).

Запускайте граф из Проигрывателя. Если открыть тот же граф в редакторе Dynamo и нажать «Запуск», не изменив код узла Python, редактор может не выполнить узел повторно и выгрузка не обновится.

## 4. Что смотреть в отчёте

| Лист | Что на нём |
|------|------------|
| Типовые этажи | Этажи сгруппированы: одинаковые — один цвет и один номер группы (например, 7–12). Справа вверху — дата и время выгрузки. |
| Таблица 1 | Этаж \| Номер \| Тип \| Комнат \| Sобщ \| Sж \| СУ \| Уборная \| Гардеробная. |
| Выгрузка | Сырые строки из Revit. Руками не править: при следующей выгрузке лист заменяется. |
| Настройки | Корпус, учёт типа квартиры, имена помещений (раздел 6). |
| Инструкция | Краткая памятка внутри книги. |

Если цифры не обновились — F9.

## 5. Повторная выгрузка того же корпуса

Файл корпуса целиком не перезаписывается: заменяется только лист «Выгрузка». «Типовые этажи» и «Таблица 1» пересчитываются по новым данным. Правки на листе «Настройки» сохраняются. Файлы других корпусов не затрагиваются: имя файла берётся из имени связи АР.

Перед запуском файл корпуса должен быть закрыт в Excel.

`Data.ExportExcel` с перезаписью удаляет лист «Выгрузка» и создаёт его заново. Обычные ссылки на этот лист превращаются в `#REF!`. Формулы шаблона читают «Выгрузку» через `INDIRECT`, поэтому после замены листа они остаются целыми.

## 6. Новый объект или другие параметры АР

Имена помещений — на листе «Настройки» (формулы не трогать):

- В столбцах СУ / Уборная / Гардеробная перечислены варианты имён. Если в АР помещение называется иначе (например, «С/у»), впишите вариант в пустую ячейку нужного столбца.
- «Учитывать тип квартиры при поиске типовых этажей»: «нет» — сравниваются только наборы помещений; «да» — ещё и типы квартир.

Имена параметров в самом скрипте (если у АР другие параметры):

1. Откройте `Выгрузка_квартирографии.dyn` в Dynamo.
2. Двойной щелчок по узлу «Выгрузка АР».
3. Измените только блок НАСТРОЙКИ вверху. Строки `KLWT_*` — пример имён общих параметров одного заказчика:

```python
P_FLOOR = "KLWT_Этаж"                     # этаж
P_TYPE  = "KLWT_Тип квартиры"             # тип квартиры
P_NUM   = "KLWT_Номер квартиры на этаже"  # номер квартиры
P_SOBSH = "KLWT_Площадь квартиры общая"
P_SZH   = "KLWT_Площадь квартиры жилая"
ROOM_NAMES = ["Совмещенный санузел", "Санузел", "Ванная", "Уборная", "Туалет", "Гардеробная"]
```

4. «Принять изменения», затем Ctrl+S.

Новое имя помещения добавляют в двух местах: в `ROOM_NAMES` скрипта (иначе помещение не выгрузится) и на листе «Настройки» (иначе оно не попадёт в столбец СУ / Уборная / Гардеробная). Для новых корпусов правьте шаблон в папке скрипта (он общий для всех проектов), для уже созданных — их файлы в папке «Квартирография».

Новый объект копировать не нужно: скрипт один, отчёты ложатся рядом с открытой моделью ОВ. Если папку скрипта перенесут, поправьте `SCRIPT_DIR` в блоке НАСТРОЙКИ и сохраните граф.

## 7. Ошибки и что делать

| Что видно | Что делать |
|-----------|------------|
| Появился `Квартирография_ОШИБКА.xlsx` | Связь АР не найдена. На листе «Выгрузка» — причина и список связей. Загрузите связь («Управление связями» → «Обновить/Загрузить»). |
| «Загружено несколько связей АР» | Впишите в поле «Связь АР» часть имени нужной связи, например `K04`. Сравнение не зависит от регистра, разделителей (`_`, пробел, `-`, `.`) и парных букв кириллица/латиница (А/A, К/K, …). |
| «Закройте файл … и запустите снова» | Файл корпуса открыт в Excel. Закройте и запустите ещё раз. |
| «Нет шаблона Квартирография_ШАБЛОН.xlsx в папке скрипта …» | Шаблона нет в папке из `SCRIPT_DIR`: его удалили или переименовали, либо путь ведёт не туда. Путь должен заканчиваться на `\Dynamo\Выгрузка квартирографии`. |
| «Модель ОВ не сохранена» | Сохраните модель ОВ и запустите снова. |
| «Модель ОВ хранится в облаке / на Revit Server» | Папку отчётов рядом с такой моделью создать нельзя. Откройте модель, сохранённую на сетевом диске. |
| «Не удалось создать папку отчётов …» | Нет прав на запись в папку модели ОВ (или файла-хранилища). |
| В отчёте нули или пусто | Нажмите F9. Проверьте, что в АР заполнены параметры из блока НАСТРОЙКИ и имена помещений совпадают с листом «Настройки». |
| Предупреждение «Use ExportToExcel instead» | На результат не влияет. |

## 8. Ограничения

- На компьютере должен быть установлен Microsoft Excel (`Data.ExportExcel`).
- Revit 2024, узел Python — CPython3.
- До 15 квартир на этаже, 80 этажей, 1500 квартир, 3000 строк выгрузки на корпус.
- Макросов нет. Файл `.xlsx` открывается в Excel 2010 и новее.
- Скрипт только читает помещения связи АР. Модель ОВ он не сохраняет и не синхронизирует. На диск он пишет папку «Квартирография» и файл корпуса.
